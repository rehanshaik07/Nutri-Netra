# 🥗 Nutri-Netra – Smart Meal Monitoring System

## 📌 Overview  
Nutri-Netra is a web-based system designed to monitor and improve meal quality, attendance, and food wastage in institutions like schools or colleges.

---

## 🚀 Features  
- 📊 Dashboard with analytics  
- 🍽️ Weekly menu with nutrition details  
- 📅 Attendance tracking  
- 🗑️ Food wastage analysis  
- 💬 Feedback system  
- 🔐 Login system (Admin & Student)  

---

## 🛠️ Tech Stack  
- HTML, CSS, JavaScript  
- PHP  
- MySQL  

---

## ⚙️ Setup  
1. Clone repo  
2. Move to htdocs  
3. Start XAMPP  
4. Import database  
5. Run on localhost
